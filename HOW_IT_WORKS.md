## 🔧 الكود الأساسي

### 1. تحميل التصنيفات
```javascript
getCategories() {
    this.$axios.get('/api/categories')
        .then(response => {
            this.allCategories = response.data.data;
        });
}
```

### 2. عرض التصنيفات
```javascript
computed: {
    displayCategories() {
        if (!this.currentCategory) {
            // عرض الرئيسية
            return this.allCategories.filter(
                cat => !cat.parent_id
            );
        }
        // عرض الفرعية
        return this.allCategories.filter(
            cat => cat.parent_id === this.currentCategory.id
        );
    }
}
```

### 3. اختيار تصنيف
```javascript
selectCategory(category) {
    if (category.children_count > 0) {
        // حفظ الحالي في السجل
        this.categoryHistory.push(this.currentCategory);
        // تعيين الجديد
        this.currentCategory = category;
    } else {
        // تصنيف نهائي
        this.currentCategory = category;
    }
    // تطبيق الفلتر
    this.applyFilters();
}
```

### 4. الرجوع
```javascript
goBack() {
    // استرجاع من السجل
    this.currentCategory = this.categoryHistory.pop() || null;
    // تطبيق الفلتر
    this.applyFilters();
}
```

### 5. تطبيق الفلاتر
```javascript
applyFilters() {
    let filters = {};
    
    if (this.currentCategory) {
        filters.category_id = this.currentCategory.id;
    }
    
    if (this.appliedPrice) {
        filters.price = this.appliedPrice;
    }
    
    // إرسال للمكون الأب
    this.$emit('filter-applied', filters);
}
```


## 🎯 النقاط الرئيسية

### ✅ المميزات
1. **ديناميكي**: لا hardcoding
2. **هرمي**: تنقل متعدد المستويات
3. **ذكي**: عرض الفرعية فقط
4. **سريع**: بدون reload
5. **موبايل**: زر عائم + درج
6. **عربي**: RTL كامل

### 🔑 المفاهيم الأساسية
- `allCategories`: جميع التصنيفات
- `currentCategory`: التصنيف الحالي
- `categoryHistory`: سجل التنقل
- `displayCategories`: ما يظهر للمستخدم
- `parent_id`: للربط الهرمي
- `children_count`: للتحقق من الفرعية

### 📊 البيانات
```javascript
category = {
    id: 5,
    name: "إلكترونيات",
    parent_id: null,
    children_count: 3
}
```
